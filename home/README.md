# Seven Valleys International Preschool — Homepage

A premium, playful, responsive HTML/CSS/JS homepage starter based on the supplied logo and Option 1 palette.

## Run
Open `index.html` in a browser. No build step is required.

## WhatsApp
Edit `WHATSAPP_NUMBER` near the bottom of `script.js` and use digits only, including country code.
Example: `919876543210`.

## Demo imagery
The supplied brand assets are in `assets/`. Demo classroom/teacher/premise photos use Unsplash URLs so the page can be previewed immediately. Replace those URLs with the school's final compressed WebP/JPG assets for production.

## SEO
Includes title, description, keywords, Open Graph basics and a `Preschool` JSON-LD block. Replace `https://example.com/`, phone, address and social profiles before launch.

## Next pages
The same design system can be extended into About, Admissions, Academics, Gallery and Contact pages.
